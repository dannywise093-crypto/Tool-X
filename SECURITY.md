# Security Policy

## Responsible use

Tool-X is intended for legitimate development, administration, and authorized security research.

Only test systems and data when you own them or have explicit authorization. Do not use Tool-X to gain unauthorized access, disrupt services, steal credentials or data, deploy malware, or evade security controls.

## Reporting a security issue

If you discover a vulnerability in Tool-X or a catalog/installer issue that could create a security risk, please open a private security report through GitHub when available, or open a repository issue without publishing sensitive exploit details.

When reporting, include:
- affected Tool-X version or commit;
- affected file or feature;
- steps needed to reproduce the issue in a safe test environment;
- expected and observed behavior;
- any relevant logs with secrets removed.

Do not publish credentials, tokens, private data, or working attack instructions in an issue.

## Catalog safety

Tool-X may reference third-party and dual-use software. Catalog inclusion is not an endorsement of misuse. Maintainers may disable entries that cannot be safely supported or that conflict with platform or repository policies.
